# NorthStar

**Open-source AI development tools built around local and cloud models.**

NorthStar is an open-source project by **Drivix Media**, developed in collaboration with **Waypoint Games**.

The goal of NorthStar is to create flexible AI development tools that can combine local and cloud models, giving developers control over how their AI-assisted workflows operate.

## Projects

### NorthStar Agent

An AI development agent designed to understand projects, analyze code, assist with debugging, and eventually perform controlled development tasks.

The agent is intended to support both local and cloud AI models rather than being tied to a single provider.

### NorthStar Nonexistent Project

A testing and experimentation project for NorthStar.

This project exists to provide a safe environment for testing NorthStar's abilities before giving it access to real projects.

## Current Status

NorthStar is in early development.

The current prototype is being tested with **Ollama** and local AI models, with cloud-model support planned.

## Philosophy

NorthStar is intended to be:

* Open source
* Model-agnostic
* Developer-focused
* Locally capable
* Extensible
* Transparent about what it changes

The goal is to build tools that developers can understand, modify, and control.
